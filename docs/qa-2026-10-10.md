## Fixes found during testing

Browser Firebase auth now uses browser persistence and one app component registry. Tamagui form DOM events are bridged to native-style callbacks. Plain theme colors are used outside Tamagui, avoiding browser parsing errors for CSS variables. Web dialogs and action menus provide real keyboard-accessible confirmation/actions. Mobile Firestore must use its React Native entry: the browser entry enables Fetch streams even when long-polling is selected, which stalled native profile listeners after the Firebase dependency update. Metro pins the shared app registry and chooses each platform's correct transport.

Report submission binds the authenticated reporter, snapshots actual server message evidence and retries one stable reference. A separate failed block can be retried without duplicating a report. Moderator claims are required; decisions produce a private audit record and cannot downgrade a ban. Review outcomes and timestamp-exact pagination have integration coverage. A saved report now returns to My reports with an inline blocked confirmation and clean back navigation.

The pinned reports header no longer shrinks when a long native report list loads; the back control and full title stay visible. Onboarding tests dismiss the iOS numeric keyboard by tapping the form background, then scroll preference controls into view. Sign-in waits for transitions and dismisses the simulator's delayed password-saving prompt when it appears.

Native UI tests wait for loaded conversations and dismiss only React Native’s development warning migration notice, which otherwise covers the composer. App errors remain visible and the real send/report assertions are retained.

QA emulators use isolated temporary function/rule copies and disabled provider secrets. The runner refuses occupied ports and preserves developer environment/secrets and other test-server groups.
